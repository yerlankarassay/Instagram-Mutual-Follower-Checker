# Instagram-Mutual-Follower-Checker
I wrote a Python script that gives you the Instagram usernames of people that you follow but don't follow you back.

# How to use the program
#1: Login to your Instagram account and download Followers and Following Data
To locate the files go to: Settings/Privacy Center/Your informations and permissions/ Download your information/ Click Some of your information/ Followers and Following/ Click 'Download to Device'/ Select Date Range: Alltime and Format: JSON/ Create Files

#2 Have some tea or coffee as Instagram prepares the files for you (approximate waiting time 5 minutes)

#3 Change the names of the files to 'following.json' and 'followers.json' if not named as such already

#4 Drag the files into the same directory as the script

#5 Run the Python script
You will be given the usernames of every single person that you follow but that doesn't follow you back sorted in alphabetical order.
